## Projetos em Destaque

Aqui estão os principais sistemas desenvolvidos para o meu portfólio, focados em cenários e problemas reais de mercado:

### 📔 [Contact Management API (Agenda de Contatos)](https://github.com)
API RESTful completa desenvolvida com as melhores práticas de engenharia de software do ecossistema Spring.
- **Destaques Técnicos:** Arquitetura em 4 camadas, imutabilidade com Java Records (DTOs), validação de payloads (`Bean Validation`), controle de transações relacionais (`@Transactional`) e gerenciamento centralizado de erros globais (`@RestControllerAdvice`).
- **Tech Stack:** Java 17+, Spring Boot 3, Spring Data JPA, H2 Database, Lombok.
